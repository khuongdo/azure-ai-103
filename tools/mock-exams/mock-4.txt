=== D1 single
Q: A voice assistant uses a reasoning model for short intent classification, and users complain about a long pause before every answer. Accuracy is already high. Which change reduces latency the most?
+ Set `reasoning_effort` to `none` for this latency-critical task :: Reasoning models produce hidden reasoning tokens before the first visible token. A lower effort (or `none`) removes most of that wait.
- Add "think step by step" to the prompt :: This adds tokens and is not recommended for reasoning models.
- Increase `max_output_tokens` to 100,000 :: A larger cap does not make the model faster.
- Move the deployment to Batch :: Batch is asynchronous with a 24-hour target.

Q: A product team plans to run a production workload on a model labeled Preview because it has the best benchmark results. Which risk should you point out, based on the model lifecycle?
+ Models move from Preview to GA, then Deprecated and Retired; production workloads need a GA model and a replacement plan, with notices and pinned versions :: When a model retires, deployments stop working, as happened with `dall-e-3` on March 4, 2026.
- Preview models are always more expensive than GA models :: Price is not the lifecycle risk.
- Preview models cannot be deployed in Foundry :: They can be deployed, but they are not meant for production.
- Benchmarks are invalid for Preview models :: Benchmarks exist but do not replace testing on your own data.
