# Question bank by domain

The ten [mock exams](index.md) mix all five domains. This section regroups the same 500 questions **by exam domain**, so you can drill one weak domain at a time. Each bank is an interactive set with the same engine as the mock exams: practice mode, exam mode, timer, grading, and an explanation for every option plus a concept block for every question. Below each set are the **flashcards** from the topic quizzes of that domain (300 in total), as cards you open one by one.

## How to use it

1. Take a full [mock exam](index.md) and read the score by domain.
2. Open the bank of your weakest domain and work in **practice mode** until the concept blocks feel easy.
3. Re-take the bank in **exam mode** and aim for 80% or more. The default timer is scaled to the bank size (2.4 minutes per question, like the real exam pace); choose "No timer" if you prefer.
4. Use the lessons linked at the bottom of each bank to fill gaps.

The banks are generated by `tools/mock-exams/build_mock_exams.py` together with the mock exams, so they always match the tests. The questions are the same as in the mock exams, not new ones, and they are not real exam questions.
