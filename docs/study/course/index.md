# AI-103 course: syllabus and study plan

This is the full path through the notes, organized by exam domain. For each domain: read the deep dives, then the real-world pages, then take the quizzes. Hours are **suggested estimates**, not Microsoft figures.

Use the [coverage matrix](coverage-matrix.md) to check that every skill area has a page and a quiz.

## How to study each lesson

1. **Read** the deep dive (30 to 60 minutes). Follow every step of each flow.
2. **Apply** with the matching real-world case study.
3. **Test** yourself with the quiz; redo wrong answers after a day.
4. **Review** [exam tips](../exam-tips/index.md) at the end of each domain.
